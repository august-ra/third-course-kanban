# Канбан

Учебный проект по отображению и организации задач внутри команды разработчиков.
Проект написан на __React__ с использованием сборщика __Vite__.

Для запуска необходимо:

- запустить dev-сервер посредством команды `npm run dev`
- сделать сборку, используя `npm build`

### Чек-лист:

- При первом запуске приложения просит пользователя авторизоваться.
- Если пользователь впервые на сайте — то он может зарегистрироваться.
- Учётные данные пользователя сохраняются в браузере на компьютере и второй раз пользователь может не вводить пару значений «логин-пароль».
- Пользователь может выйти из-под учётной записи, тогда он повторно будет отправлен на страницу авторизации.
- После успешной авторизации/регистрации пользователь автоматически перейдёт на главную страницу с задачами.
- При загрузке приложения со страницей задач появляется анимация загрузки на время получения текущих задач с сервера.
- Список задач представлен пятью группами в соответствии с этапами выполнения, новых групп добавить возможности нет.
- Каждая задача имеет в себе тег, окрашенный соответствующим цветом. Всего тегов три, и возможности добавить новые теги нет на данный момент.
- При нажатии на (1) кнопку с многоточием в правом углу каждой задачи или на (2) название задачи открывается окно просмотра задачи с возможностью отредактировать её или удалить.
- При нажатии на кнопку «Создать задачу» открывается окно добавления новой задачи, в котором пользователю необходимо заполнить все поля.
- Все изменения задач (добавление, редактирование, удаление) отправляются на сервер и могут получены всеми зарегистрированными пользователями.
- Если пользователь оставит незаполненными поля с названием и описанием, неуказанные тег и дату исполнения задачи — внизу модального окна будет отображён текст ошибки.
- В случае успешного заполнения всех полей появится соответствующее сообщение об успешном завершении действия и автоматический переход на следующий этап.
- Пользователь может изменить тему приложения со светлой на тёмную и наоборот, используя переключатель в выпадающем модальном окне под ссылкой с именем пользователя.
